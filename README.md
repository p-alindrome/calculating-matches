# 😌 Calculating Matches

A highly accurate matchmaking simulator.

## 🧠 What is this?
**Calculating Matches** is a sarcastic, chaotic, single-page website that pretends to calculate potential romantic matches — with extremely honest results.

Perfect for:
- Singles
- Self-aware people
- Group chats
- Coping via humor

## 🔄 How it Works
1. Fake loading screen with escalating chaos
2. Progress bar that looks serious (it’s not)
3. Brutally honest final result
4. Judgmental “Try Again” button

## ✨ Features
- Fake system messages
- Animated progress bar
- Chaotic & sarcastic humor
- Clean, modern UI
- One HTML file, zero dependencies
